# 스모크 존 레이더 (Smoke Zone Radar)

서울에서 처음 가는 동네에 간 흡연자에게 **반경 100m 안 흡연구역**을 알림으로 알려주고,
**학교·어린이집·유치원 근처 금연구역**에 들어가면 "과태료 대상일 수 있다"고 미리 경고해주는 모바일 웹앱.

## 주요 기능
| 기능 | 설명 |
|---|---|
| 흡연구역 레이더 | 반경(50/100/200/300m) 안에 들어가면 알림음·진동·휴대폰 알림. 머무는 동안 정한 간격(1·3·5·10분)마다 다시 알림 |
| 요약 알림 모드 | 정한 간격마다 "주변 N곳, 가장 가까운 곳은 어디"를 묶어서 알림 |
| 가장 가까운 곳 안내 | 반경 안에 없으면 가장 가까운 곳과 도보 시간, 카카오 길찾기 |
| 금연구역 경고 | 학교·어린이집·유치원 주변에 들어가면 경고 카드·경고음·휴대폰 알림 |
| 금연구역 지도 표시 | 지도를 동네 수준(줌 15 이상)으로 확대하면 금연구역을 빨간 원으로 표시 |
| 낯선 곳 모드 | 집·학교 등 자주 가는 곳을 등록하면 그 주변 300m에서는 흡연구역 알림을 쉼 |
| 이동 중 자동 멈춤 | 시속 15km 이상(버스·차)이면 알림을 잠깐 멈춤 |
| 방해 금지 시간 | 정한 시간에는 소리·진동·휴대폰 알림을 끔 |
| 흡연구역 종류 구분 | 실외·부스 / 건물 흡연실 / 업소(이용객 전용, 기본 숨김) |
| 가상 걷기 시뮬레이터 | 발표·테스트용. 지도를 탭하면 그쪽으로 걸어가며 알림이 오는지 확인 |

## 폴더 구조
```
smoke-radar/
├─ index.html              화면
├─ sw.js                   휴대폰 알림용 서비스워커
├─ manifest.webmanifest    홈 화면에 추가(앱처럼 쓰기) 설정
├─ assets/
│  ├─ css/style.css        디자인
│  ├─ js/app.js            동작 코드
│  ├─ img/                 아이콘
│  └─ vendor/leaflet/      지도 라이브러리 (Leaflet 1.9.4, BSD-2)
├─ data/
│  ├─ smoking-areas.js     서울 흡연구역 1,075곳
│  └─ no-smoking-points.js 금연구역 기준 시설 2,264곳 (학교·유치원·어린이집)
├─ tools/geocode_kakao.rb  흡연구역 좌표 보정 스크립트 (카카오 API)
├─ server.rb               내 컴퓨터에서 켜보기용 서버
├─ netlify.toml            Netlify 배포 설정
└─ AGENTS.md               Antigravity 에이전트 작업 규칙
```

## 내 컴퓨터에서 켜보기
```bash
ruby server.rb
# → http://localhost:3000
```
(ruby가 없으면 `python3 -m http.server 3000` 도 됨)

## 배포 (GitHub → Netlify 자동 배포)
1. GitHub에 이 폴더를 저장소로 올린다.
2. Netlify에서 저장소를 연결한다. 빌드 설정은 `netlify.toml`을 자동으로 읽으므로 비워두면 된다.
3. 이후 `git push` 할 때마다 1~2분 안에 자동 배포된다.

> 위치·알림 기능은 **https** 주소에서만 동작한다. Netlify 주소(…netlify.app)는 https라 그대로 된다.
> 아이폰은 사파리에서 "홈 화면에 추가" 후 열어야 휴대폰 알림을 받을 수 있다.

## 데이터 출처와 한계
- **흡연구역**: 서울시 자치구 흡연시설 공공데이터(이름·주소). 원본에 좌표가 없어 주소로 추정한 좌표라 **검증 전**이다.
  `KAKAO_REST_KEY=키 ruby tools/geocode_kakao.rb` 로 카카오 좌표로 보정하면 `verified` 표시가 붙고,
  위치를 못 찾은 곳은 목록에만 보이고 알림에서는 빠진다.
- **금연구역**: 공공데이터포털 전국초중등학교위치표준데이터(운영 중인 서울 학교 1,343곳, 특수학교 포함),
  전국어린이보호구역표준데이터(서울 유치원 462곳·어린이집 459곳). 어린이집·유치원은 어린이보호구역 대상 시설만 있어 **서울 전체의 일부**다.
- 법 기준: 어린이집·유치원·초중고 시설 경계 30m 이내 금연구역, 위반 시 과태료 10만원 이하(국민건강증진법, 2024.8.17 시행).
  데이터는 경계선이 아니라 점 좌표라 지도 원은 **대략적인 범위**(학교 70m, 유치원·어린이집 45m)로 그렸다.
- 버스정류소·지하철 출입구·공원 등 구청 지정 금연구역은 아직 없다 → 다음 보강 대상.
- 위치 정보는 기기 안에서만 쓰고 서버로 보내지 않는다.
